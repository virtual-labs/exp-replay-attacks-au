Network Graph simulating a replay attack on a client/server connection

Aim
To simulate and visualize a replay attack on a client/server connection using a network graph, allowing users to observe how packets are intercepted or protected based on protocol (HTTP/HTTPS).

Expected Outcome
Observe the difference in packet interception between HTTP and HTTPS. HTTP packets can be intercepted and modified by the attacker (MITM), while HTTPS packets remain encrypted and protected.
  • Choose the number of clients and servers required and click on "Generate Graph" to generate the graph.
  • Click on a client and a server to send packets between client and server.
  • Observe the log page to view step-by-step events.
